# Contributing

Additions, corrections and removals are all welcome. Open a pull request that
changes one section, and say in the description why the entry earns its line.

## What gets in

- **It solves a problem the list names.** Fetching a page that blocks you,
  parsing what comes back, or keeping the thing running next month.
- **It is maintained**, or it is a classic that still works and is labelled as
  unmaintained.
- **It is usable by someone who found it here** — public repository or public
  docs, not a waitlist and not a login wall.

## What does not

- Anything paid for or exchanged. There is no arrangement under which an entry
  can be bought, and there will not be one.
- Rewrites of an existing entry under a new name.
- Tools whose only description is that they are powerful, fast and easy to use.
- Anything sold specifically as a way to defeat a named site's protections.
  Generic anti-bot tooling is in scope; "bypass $SITE's login" is not.

## Format

One line per entry, alphabetical within its section:

```markdown
- [Name](https://example.com) — what it is, and what it is good at, in one sentence.
```

Use an em dash, no trailing full stop on fragments, and describe the tool
rather than praise it. Link to the repository for open-source projects and to
the product page for services.

## Removals

Open an issue rather than a PR if you think something should go — dead links,
abandoned projects, or a service that has quietly stopped being one. Removals
are as valuable as additions and the list gets one full pass of them a year.
